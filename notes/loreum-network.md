## Loreum AI Network

The Loreum AI Network is a decentralized system that allows users to submit queries to a network of interconnected nodes. These nodes collaborate to process queries efficiently and distribute workloads across the network.

![Loreum Network Architecture](../static/img/loreum-network.png)

### Technical Architecture

1. Query Flow
- User submits query to entry node (n)
- Query routed through Loreum Cortex Network
- Distributed processing across node network (n2, n3, n4)

2. Network Structure
- Decentralized P2P node network
- Dynamic workload distribution
- Specialized node capabilities
- Horizontal scaling via node addition

3. Technical Properties
- Asynchronous inter-node communication
- Independent node operation

The Loreum Cortex Network provides decentralized query processing through a scalable network of specialized nodes, enabling distributed AI computation.
